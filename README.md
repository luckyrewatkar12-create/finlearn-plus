# 📅 Daily Log — GitHub Contributions

A daily journal to track my learning, projects, and progress as a developer.

## 🎯 Goal
Make consistent daily contributions on GitHub and document my growth.

## 📁 Structure
```
log/
└── YYYY-MM-DD.md   ← one file per day
```

## 🚀 How to use
Each day:
1. Create a new file in the `log/` folder named with today's date (e.g. `2026-09-11.md`)
2. Write what you learned, built, or worked on
3. Commit and push
